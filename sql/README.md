เก็บไว้ดูย้อนหลังเฉย ๆ ว่าเคยแก้อะไรไป **ไม่ต้องรันซ้ำ**

- `fix-dispatched-at.sql`, `audit-dispatch-dates.sql` — แก้วันที่จ่ายออกของข้อมูลชุดเก่า ซึ่งถูกล้างไปแล้ว (24 ส.ค. และ 29 ก.ย. 2569) ถ้าวันหนึ่งวันที่จ่ายออกเพี้ยนอีก ใช้เป็นแบบได้

## วิธีใช้

1. เปิดไฟล์ อ่านหมายเหตุข้างในก่อน — บางไฟล์ต้องแก้ SN หรือวันที่ให้ตรงกับของจริง
2. ก๊อปทั้งไฟล์ไปวางใน SQL Editor
3. กด Run
4. เสร็จแล้วกลับไปที่แอป กด **ออกจากระบบ** แล้วล็อกอินใหม่ — แอปโหลดข้อมูลตอนล็อกอินครั้งเดียว ไม่ล็อกอินใหม่จะยังเห็นข้อมูลเก่า

## กับดักที่เจอบ่อย

**`update` ขึ้น `Success. No rows returned` เสมอ** ไม่ว่าจะแก้โดนกี่แถว
แม้แต่ 0 แถวก็ขึ้นแบบนี้ ดูไม่ออกว่าสำเร็จจริงไหม

แก้ด้วยการต่อท้าย `returning` — มันจะโชว์แถวที่แก้ไปจริง ๆ ออกมาเป็นตาราง
ถ้าตารางว่าง แปลว่าไม่โดนสักแถว:

```sql
update inventory set dispatched_at = '...' where sn = '...'
returning sn, dispatched_at;
```

ไฟล์ในโฟลเดอร์นี้ใส่ `returning` ไว้ให้หมดแล้ว

**เวลาต้องมี `+07` ต่อท้ายเสมอ** เช่น `'2026-08-24 10:10:00+07'`
ถ้าไม่ใส่ Postgres จะคิดเป็นเวลา UTC แล้วในแอปจะกลายเป็นบ่าย 5 ของวันนั้น
